# Escape Disaster: Educational Survival Game 🏃‍♂️🌋

> **🏅 Competitive Submission for the Disaster Education Media Competition (DEMC) U-DARE 3.0** organized by TDMRC USK.

Escape Disaster is an interactive, mobile-ready educational game designed to teach elementary students vital self-rescue procedures during natural emergencies, specifically earthquakes and tsunamis. By simulating high-pressure scenarios, the game trains quick thinking and life-saving decision-making in a safe, engaging environment.

This project highlights a seamless collaboration between visual design and interactive programming to create an impactful learning tool for children.

## ✨ Key Features
* **Emergency Simulations:** Puts players in immersive, simulated disaster scenarios requiring immediate action.
* **Time-Limited Quizzes:** Tests students' critical decision-making under pressure using countdown mechanics to simulate real-world urgency.
* **Child-Friendly UI/UX:** Features custom-designed, engaging visual assets specifically tailored to hold the attention of elementary school students.
* **Smooth Performance:** Built using the TurboWarp engine to compile block-based logic into highly optimized JavaScript, ensuring smooth gameplay on both PC and mobile devices.

## 🛠️ Tech Stack
* **Game Engine:** TurboWarp (Advanced Scratch Engine)
* **Programming Paradigm:** Visual Block-Based Programming
* **Deployment:** HTML5 / Web (via TurboWarp Packager)

## 💻 View & Edit the Source Code
If you want to look at the block logic or edit the game:
1. Download the `EscapeDisaster.sb` project file from this repository.
2. Open your browser and go to [TurboWarp](https://turbowarp.org/) (an advanced Scratch mod that compiles to JavaScript).
3. Click on **File** > **Load from your computer** in the top left menu.
4. Select the downloaded `.sb` file. (TurboWarp automatically supports this format).
5. Click the **Green Flag** to run the game, or click **See Inside** to explore the code structure.
